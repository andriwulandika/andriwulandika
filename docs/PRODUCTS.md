# PRODUCTS (Produk Digital)

## Produk 1 — Platform AI Tools Perencanaan Daerah (`ai.andriwulandika.uk`)
Platform 8 AI tools + template + regulasi untuk ASN perencana daerah. Model pay-as-you-go
(kredit) + demo gratis. Detail model: `BUSINESS_MODEL.md`; mesin: `AI_STRATEGY.md`.

### 8 AI Tools (SiTool)
| Tool | File | Dokumen yang dibantu |
|---|---|---|
| SiRENJA | `sirenja.html` | Renja OPD |
| SiRKPD | `sirkpd.html` | RKPD & Perubahan RKPD |
| SiKTOR | `siktor.html` | KAK / TOR |
| SiLKjIP | `silkjip.html` | LKjIP |
| SiPerda | `siperda.html` | dokumen/naskah terkait Perda |
| SiGenDok | `sigendok.html` | generator dokumen umum (terbesar, 2512 br) |
| SiBACARA | `sibacara.html` | Berita Acara Rapat |
| SiTelaah | `sitelaah.html` | Nota Dinas / Telaahan Staf |

### Aset pendukung produk
- **Template dokumen** (`template.html` + `assets/templates/`): .doc/.xls + contoh HTML
  (Renstra, Renja, PK, LKjIP, cascading, dll).
- **Regulasi** (`regulasi.html`): rujukan regulasi perencanaan.
- **Data nomenklatur** (`assets/data/nomenklatur/`): 60+ JSON program/kegiatan/sub-kegiatan.
- **15 artikel panduan** (SEO + edukasi): Renja/Renstra lengkap, SAKIP, cascading, RKPD,
  IKU SMART, KAK/TOR, Nota Dinas vs Telaahan, Berita Acara, kesalahan umum, cara pakai template, dll.

### Halaman transaksi
`harga.html` (⚠️ selaraskan pesan "tanpa batas" → kredit), `bayar.html`, `aktifkan-pro.html`,
`panduan-kredit.html`, `dashboard.html`, `admin-kode.html` (admin, noindex).
