# PORTFOLIO STRATEGY

## Masalah saat ini (pengungkit konversi #1)
Portofolio homepage = **1 proyek nyata** (`ai.andriwulandika.uk`, "Live") + **2 placeholder**
"Segera" (mockup company profile & landing page). **Tanpa testimoni klien nyata.** Ini penghambat
kepercayaan terbesar untuk ketiga ICP (`AUDIT_REPORT.md` #14, #22).

## Tujuan
Ubah portofolio dari "janji" menjadi "bukti": tunjukkan hasil nyata + suara klien → naikkan
konversi WhatsApp.

## Strategi
1. **Jadikan platform AI Tools sebagai studi kasus unggulan.** Sudah "Live" — perkuat dengan
   angka (jumlah tool, artikel, pengguna bila ada) & tautan langsung. ✔ sebagian ada.
2. **Kumpulkan bukti dari setiap proyek jasa.** Setiap website klien selesai → minta izin tampil +
   1–2 kalimat testimoni. Bangun pustaka minimal 3–6 item sebelum menghapus placeholder.
3. **Studi kasus terstruktur** (per proyek): masalah → solusi → hasil → (idealnya) testimoni.
   Format ringan, bisa jadi halaman/section, bukan aplikasi baru.
4. **Testimoni** dengan atribusi jelas (nama, peran, instansi/usaha) — hindari testimoni anonim.
5. **Sementara placeholder ada:** beri label jujur ("Contoh Desain", bukan mengesankan klien nyata)
   — sudah dilakukan; jangan pernah memalsukan klien.

## Aturan integritas (wajib)
- **Tidak memfabrikasi** klien/testimoni/logo. Kepercayaan brand = aset utama (`POSITIONING.md`).
- Tampilkan hanya dengan **izin** klien.
