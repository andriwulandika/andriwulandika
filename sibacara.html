Cara mendapatkan API Key Gemini (gratis):
  1. Buka aistudio.google.com/app/apikey
  2. Login akun Google → klik Create API key
  3. Pilih project → klik Create API key in existing project
  4. Copy key yang muncul (diawali AIzaSy... atau AQ.)
  5. Paste di kolom di bawah → klik Simpan
