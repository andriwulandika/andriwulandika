# web-next — scaffold eksperimental (belum live)

Next.js 16 (App Router) + TypeScript + Tailwind CSS v3, terisolasi total dari
`site/`/`tools/` yang deploy ke Cloudflare Pages. Lihat
`docs/adr/0002-nextjs-tailwind-migration.md` di root repo untuk konteks
keputusan, scope, dan langkah selanjutnya sebelum ini menggantikan apapun
di produksi.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Build

```bash
npm run build
```
